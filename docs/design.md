# ヴァンパイア・ハウス — ルール確定版

企画書（`docs/concept.md`）に残されていた「未決定事項」を、実装とバランス調整を通して
すべて確定させたもの。数値の根拠は末尾のシミュレーション結果に基づく。

---

## 0. 盤面はルールそのものを描いた図形

以前は、渡してもらった盤面写真をそのまま背景に敷き、写真とのズレを画面上で
人力ドラッグして合わせる「盤面調整モード」を用意していた。写真という
**先に確定した見た目**に当たり判定を後から合わせようとした結果、
本来ルールから機械的に決まるはずの座標（同心円の半径・8等分の角度）を
毎回目視調整する羽目になり、やることが逆だった。

正しい順序は、①ルール（§1）を満たす盤面をシンプルな幾何図形として実装し、
②デジタルでテストプレイと調整を重ねてルールを確定させ、③**最後に**、
その時点で確定している当たり判定に合わせてデザイン画像を背景として敷く、
という順番のはずだった。③はまだやっていない。今の盤面は①②の状態、
すなわち**写真を使わない、ルールに沿った図形そのもの**（`src/ui/geometry.ts` が
座標計算、`src/ui/board-view.ts` がその描画とクリック判定を行う）。

座標はすべて定数として決め打ちしてある（`RING_RADII`・`CASTLE_DISTANCE`・
`SECTOR_ANGLE`）。同心円4本を等間隔に、8方向を等角度に置くだけなので、
写真とのすり合わせや `localStorage` への保存は不要になった。
当たり判定はマス中心を囲む円（半径はリング幅と弧の長さから自動計算）。

| 位置と記号（盤面図形が表すもの） | ルールとして実装したもの |
| --- | --- |
| 中心の赤い円（村） | ここで**血を1個獲得**できる、という規則 |
| 四隅の菱形（城） | それが**プレイヤーの拠点**で、**持ち帰るまで得点にならない**という規則 |
| 緑の扇形（洞窟） | 触れると**コウモリを1枚引ける**、同じ洞窟は**1夜1回**という制限。**日陰も兼ねる** |
| 水色の扇形（テント） | 夜明けをやり過ごせる**避難所**。**2マスだけ・定員1** |
| 金の三角×2（ハンター） | **1ラウンドに1マスずつ周回する**という運動法則、触れたら即死という規則 |
| （時間の概念なし） | **4ラウンドで夜明け**、**4夜で終了**、**最終夜は得点3倍**という時間設計 |
| （移動の概念なし） | **1ターン3歩**、**血を2個持つごとに1歩遅くなる**という移動規則 |
| （他プレイヤーとの関係なし） | 同じマスに踏み込めば**血を1つ噛み取る**、仕留めた相手の血は**奪った側のもの**になる |

ハンターの数は2体。3体にする案も試したが、ボット対戦で明らかにバランスを
崩したため不採用にした（§5・§7）。

デザイン画像（`src/assets/board.png`）は破棄していないが、現時点では
どこからも参照していない。使うなら、今の当たり判定（座標定数）を動かさずに、
その座標へ絵のほうを合わせ込む形で背景に敷く。

## 1. 盤面

同心円4リング＋放射線8本。すべてのリングが8マスに分割されているので、
放射方向の接続は 1:1 で素直に対応する。

| 位置 | マス数 | 内容 |
| --- | --- | --- |
| 中心（リング0） | 1 | **村**。血の唯一の供給源。8方向すべてのリング1マスと繋がるハブ |
| リング1〜4 | 各8 | 通常の移動路 |
| リング4の外側 | 4 | **城**。四隅（斜め方向のセクター1・3・5・7）にぶら下がる |

- **洞窟（緑）**: リング3のセクター0・2・4・6。城の直通ルートから横に1歩ずれた位置。
  コウモリが引けるうえに、**岩陰が陽を遮るので日陰も兼ねる**
- **テント（水色）**: リング2のセクター0・4の**2マスだけ**。ハンターの巡回リング上にある
- **避難所は洞窟4＋テント2の計6マス。すべて定員1人**。最外リング（城の目と鼻の先）には1つも無い
- 城 → 村は最短5歩。往復10歩

```
        城              城
          \            /
           +--------- 外周リング4（避難所なし）
            +-------- リング3（洞窟4＝コウモリ＋日陰）
             +------- リング2（テント2・ハンター巡回）
              +------ リング1
               (村)
```

避難所を8マスから6マスへ減らし、そのすべてを盤の内側へ寄せたのは、
**外周に避難所があると「帰るか隠れるか」の判断が消えてしまう**ため。
城まであと1歩の場所で朝を待てるなら、それは引き際の判断ではなく作業になる。
いまは、外へ出た以上は「城まで戻る」か「盤の内側にある6つの椅子を1つ取る」かの
二択しかない。人数が増えるほど椅子は足りなくなる（4人戦では夜明けの3分の1が避難所で迎えられ、
そのたびに誰がどこに座るかの奪い合いが起きる）。

## 2. 確定した未決定事項

| 項目 | 確定内容 | 理由 |
| --- | --- | --- |
| 移動手段 | **固定歩数**。基礎移動力3 | ダイスを入れると「予測可能な脅威／判断で死ぬゲーム」という設計原則が崩れる |
| 血の重さ | **血2つごとに移動力−1**（最低1） | 「欲張るほど帰りが遠い」を盤面の距離ではなく速度でも表現する |
| 日陰の数と配置 | **テント2マス（リング2）＋ 洞窟4マス（リング3）が兼任。すべて定員1人** | 世界観としても洞窟は陽を遮る。外周の避難所を無くして「帰るか隠れるか」を毎晩選ばせる |
| 血1つの得点 | **10点**。同時に運んだぶんは1本目10点・2本目20点・3本目30点と積み上がる | 4点で勝つゲームは、勝っても手応えが残らない。桁を上げたうえで、欲張って帰り着いたときだけ跳ね上がるようにした |
| プレイヤー間の干渉 | **噛みつき（常時）・仕留めた相手の血の強奪・干渉系コウモリ11枚** | 盤面で出会うこと自体に意味を持たせる。§6・§7 |
| 手番順 | **先手は夜ごとに1つ回る** | 同じ席が毎晩「村に一番乗り」し続ける不公平を消す |
| 日陰に隠れるコスト | **なし** | 寄り道そのものが既にコスト。二重に取ると引き際の判断が単純に「帰る」へ寄る |
| 村の血の総量 | **有限。プレイヤー数 × 5** | 枯渇は保険としての終了条件。通常はラウンド数で決着する |
| ゲーム終了条件 | **4夜（16ラウンド）経過**。村の血が尽き、誰も運搬していない場合は即終了 | 企画書の「4ターン周期の太陽」をそのまま夜の単位にした |
| 逆転要素 | **最終夜の持ち帰りは3倍** | 最終夜だけリスクの見返りが跳ね上がり、差がついていても最後の一往復で全部ひっくり返る |
| コウモリの種類と枚数 | 6種22枚（下記） | 干渉系を半分まで厚くした |

## 3. ターンの流れ

1. 手番プレイヤーの移動力が `max(1, 3 − floor(運搬中の血 ÷ 2))` に設定される
   （ターン開始時に確定。ターン中に血が増減しても変わらない）
2. 隣接マスへ1歩ずつ移動する。コウモリは1ターンに2枚まで、任意のタイミングで使える
3. **他プレイヤーのいるマスへ踏み込んだら、血を1つ噛み取る**（1ターン1回・§6）
4. ターン終了時、村にいれば血を1つ得る
5. 全員の手番が終わると **ハンターが1マスずつ進む**（踏まれた者は死亡）
6. 4ラウンド目の終わりに **夜明け** が来る

先手は夜ごとに1つずつ回る。村は全員が必ず立ち寄る場所なので、
毎晩同じ席が一番乗りし続けると、それだけで有利不利が固定されてしまう。

## 4. 太陽（夜明け）

企画書の「4ターン経過後に太陽が来る」を、**4ラウンド＝1夜** として実装した。
夜明けの瞬間、避難所（洞窟・テント）または城にいないヴァンパイアは全員焼かれる。

- 焼かれた者は運搬中の血をすべて失い、自分の城へ戻される
- 失われた血は**村へ還る**（消滅させると盤面から資源が痩せ、終盤が停滞するため）
- 手札のコウモリは失わない
- 村は安全ではない。**洞窟は安全**（岩陰が陽を遮る）
- 夜明けまでの残りラウンド数は常に画面に表示される。運の要素は一切ない

## 5. ハンター

**2体**。リング2を、盤面の反対側同士を保ったまま同じ向きに1ラウンド1マスで周回する。

- 同じマスに入る／入られると即死（運搬中の血は村へ還る。ただし他プレイヤーに
  差し向けられて死んだときだけ、血はその相手のものになる ―― §6）
- 位置も進路も完全に公開情報。盤面には次の一歩が半透明の三角形で予告される
- リング2は村へ向かうときに必ず横切るリングなので、往復のたびに計算が要る
- テント（リング2）はこの巡回路の上にある ＝ **命綱と死の罠が同じマス**

> 3人以上でハンターを3体にする案は、リング1・3・4のいずれに置いても
> 1ゲームあたりの死亡数が跳ね上がり無得点プレイヤーが増えたため不採用（§7）。

## 6. 得点とプレイヤー間の干渉

### 得点

血は城に収めて初めて点になる。**同時に運んでいる血は、1本目が10点・2本目が20点・
3本目が30点** と積み上がる（基礎点 × 1+2+…+n）。最終夜はさらに3倍。

| 同時に持ち帰った血 | 通常の夜 | 最終夜 |
| --- | --- | --- |
| 1 | 10 | 30 |
| 2 | 30 | 90 |
| 3 | 60 | 180 |

「血2つごとに移動力−1」という重さの規則と正面から噛み合っている。
2本目を抱えた瞬間に足は鈍り、夜明けまでに城へ戻れなくなる ―― けれど戻れたなら、
1本ずつ2回運んだときの1.5倍になる。**欲張るほど帰りが遠く、帰り着けたときだけ見返りが跳ねる。**

`血1つの得点` は開始画面の詳細設定から変えられる（既定10）。

### 噛みつき（カード不要・常時）

他プレイヤーのいるマスへ踏み込むと、**血を1つ奪う**。1ターンに1回まで。
**村と城では起こらない** ―― 城は各プレイヤーの聖域であり、村は全員が必ず立ち寄る
収穫地点なので、そこを狩り場にすると先に着いた者がただ搾取されるだけになる
（実際、村でも噛めるようにしたら、先手のプレイヤーが吸うそばから毎ラウンド
奪われ、無得点で終わる席が出た）。狩り場は道中 ―― **血を積んだ相手を帰り道で
待ち伏せる**のが、この盤面での PVP の形になる。

### 仕留めた相手の血

誘導・影渡りで他プレイヤーをハンターに触れさせたときだけ、
その相手が抱えていた血は**村へ還らず、仕留めた側の懐に入る**。
盤上でいちばん大きな一撃で、3本抱えた相手を仕留めれば、そのまま60点分を持ち去れる。
太陽やハンターに自滅した血は、これまで通り村へ還る。

### コウモリ（発展カード）

洞窟マスに入ると1枚引ける。同じ洞窟は一夜に1回、1ターンに引けるのは1枚まで
（夜明けですべての洞窟が復活する）。手札は伏せたまま持つ。

| カード | 枚数 | 効果 |
| --- | --- | --- |
| 疾走 | 5 | このターンの移動力 +2 |
| 誘導 | 4 | ハンター1体を隣のマスへ1歩動かす。踏まれたヴァンパイアは死に、その血は差し向けた者のものになる |
| 強奪 | 4 | 城の外にいる他プレイヤー1人から血を1つ奪う。距離は問わない |
| 影渡り | 3 | 城の外にいる他プレイヤー1人と位置を入れ替える。移動は終了 |
| 影紡ぎ | 3 | 今いるマスを今夜だけ日陰にする（夜明けで消滅） |
| 飛翔 | 3 | 空いている避難所へワープする。移動は終了。ハンターの上に降りれば死ぬ |

22枚中11枚が干渉カード（旧構成は20枚中7枚）。山札が尽きたら捨札を切り直す。

**影渡り**は新しく足した札で、避難所が6マスしかないこととセットで効く。
夜明け直前、陽の下に立たされた者が、洞窟に座っている相手と入れ替わる ――
朝を押しつけて、自分だけ助かる。相手をハンターの真上へ放り込む使い方もできる。

## 7. バランス（ボット60戦 × 各人数）

`npm run balance` で再現できる。すべてボットの自動対戦。

`npm run balance` で再現できる。すべてボットの自動対戦。

| 人数 | 平均得点 | 勝者の得点 | 無得点率 | 1ゲームの死亡数 | 奪われた血 | 勝差 | 村の残り血 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 2人 | 57.92 | 76.67 | 0% | 0.00 | 1.82 | 37.50 | 4.08 / 10 |
| 3人 | 48.94 | 76.67 | 0% | 0.27 | 2.52 | 32.50 | 6.22 / 15 |
| 4人 | 48.67 | 78.67 | 1% | 0.97 | 4.25 | 23.83 | 8.37 / 20 |

調整前（血1つ＝1点、日陰8マス、干渉なし）は次の通りだったので、
**流通する得点はおよそ10倍**になった。

| 人数 | 平均得点 | 勝者の得点 | 1ゲームの死亡数 | 勝差 |
| --- | --- | --- | --- | --- |
| 2人 | 4.86 | 6.33 | 0.63 | 2.95 |
| 3人 | 4.13 | 5.98 | 2.23 | 2.07 |
| 4人 | 3.64 | 5.18 | 3.95 | 1.10 |

狙った形になっている点:

- **1夜1往復が基準線**。城→村5歩、村→城5歩、1夜に使えるのは12歩。
  ハンターを避けて回り道すると、それだけで予定が崩れる
- **村に居座って2つ目を吸うと移動力が2に落ちる**。城までは戻れないが、
  リング2のテントまでなら2歩で届く ―― ただしそこはハンターの巡回路
- 避難所は毎晩実際に奪い合いになる。4人戦では夜明けの約3分の1（960回中284回）が
  避難所で迎えられており、6マスの椅子に4人が座ろうとしている
- 無得点で終わるプレイヤーはほぼ出ない（干渉を足しても、調整前と同じ 0〜1%）

### まだ残っている歪み

ボット同士だと **持ち帰りの88%が血1本のまま**（2人戦で 1本×279回 / 2本×36回）。
城→村→城の10歩に対して1夜が12歩なので、「1夜に1本ずつ運ぶ」が安全かつ効率的で、
2本目を狙う理由が乏しい。得点側で「2本目は20点」と傾斜をつけたが、
ボットは点数ではなく到達可能性だけで判断するため、この傾斜には反応しない。

`血2つごとに移動力−1` を `3つごと` に緩めると、ボットでも2本以上の持ち帰りが
40%まで増え、平均得点は79点（16倍）まで上がる。今回は「10倍」を目安にしたので
採用していないが、欲張りの選択肢を厚くしたいならここが効く。

### 検討して不採用にした案

| 案 | 結果 |
| --- | --- |
| 3人以上でハンター3体（リング4） | 帰り道を塞ぎすぎる。4人戦の死亡数 5.9、無得点 1.03/game |
| 同（リング3） | さらに悪化。死亡数 6.25、平均得点 2.09 |
| 同（リング1） | 村の周りが詰まり無得点 0.48/game |
| 村でも噛みつけるようにする | 先手が吸うそばから毎ラウンド奪われ、4人戦の無得点率が 1% → 8% に跳ねた |
| まとめボーナスを「2本目以降 +5点」に留める | 平均45点（9倍）。1本目10点・2本目20点の傾斜のほうが、規則として憶えやすい |
| 最終夜を2倍のまま | 平均38点（8倍）。3倍にすると最後の一往復に賭ける価値が出る |
| 血2つごと−1 の重さを緩める | 平均79点（16倍）。目安の10倍を超えるので見送り（上記） |

## 8. 実装の構成

```
src/game/     ルール本体（DOM 非依存・全テスト対象）
  board.ts    盤面の生成、隣接、最短経路
  rules.ts    状態遷移。すべての公開関数は state を破壊的に更新する
  bats.ts     コウモリの定義と山札
  ai.ts       ボット。危険マスを避けて経路を引き、夜明けから逆算して引き際を決める。
              血を積んだ相手が寄り道2歩以内にいれば噛みに行き、逃げ場が無い朝には
              避難所に座っている相手と影渡りで入れ替わる
  rng.ts      シード固定の PRNG（同じシード＝同じ展開）
src/assets/
  board.png     提供されたデザイン画像。現状どこからも参照していない
src/ui/
  geometry.ts     ルールから決まる座標定数（リング半径・角度）と、
                  各マスの中心座標・当たり判定半径の計算
  board-view.ts   同心円と扇形をそのまま描画し、円の当たり判定を重ねる
scripts/      バランス検証用のシミュレーション
```

ゲームロジックは描画から完全に分離されているので、ルール変更は
`src/game/` のテストだけで検証できる。盤面の座標はルールから機械的に
決まる定数なので、写真合わせのような手作業は発生しない。

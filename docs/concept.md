# ヴァンパイア・ハウス — 企画書（原案）

> 実装にあたって確定させたルールは [`design.md`](design.md) を参照。
> こちらは出発点となった構想をそのまま残したもの。

## ゲーム概要

「ヴァンパイア・ハウス」は2〜4人用のボードゲームをデジタル化したもの。
インカの宝石（チキンレース的な引き際の判断）とカタン（リソース管理・発展カード）を融合させた、移動＋リソース回収＋生存判断のゲーム。

## 盤面構造

- **同心円＋放射線のグリッド盤面**: 中心に向かって複数のリング（ループ）があり、放射状の線で区切られたマス目で構成される
- **中心 = 村（赤丸）**: 血（ポイント資源）を獲得できる唯一の場所
- **四隅 = 城（プレイヤーのスタート地点）**: 各プレイヤーの拠点。血を持ち帰ることでポイントに変換される
- **緑マス = 洞窟**: コウモリ（発展カード的アイテム）を獲得できる場所。城から村への道の途中にある
- **水色マス = 日陰**: 太陽（朝）が来たとき、ここにいれば死なずに済む避難所

## コア・メカニクス

### 1. 移動
- プレイヤーは毎ターン、同心円に沿って横移動するか、放射線に沿って内側/外側へ移動する
- 移動手段（ダイス / 固定歩数 / カード選択）は要テストプレイで決定
- 盤面の構造上、村に近づくほど城（ゴール）から遠くなる

### 2. 血の回収と持ち帰り
- 村（中心の赤丸）に到達すると血トークンを獲得できる
- 血を持ったまま自分の城（四隅）に帰還するとポイントとして確定する
- **持ち帰るまではポイントにならない**（途中で死ぬと全ロスト）
- ゲーム終了時に最もポイントの多いプレイヤーが勝利

### 3. 太陽（朝）システム
- **4ターン経過後、次のループ（リング）の境界で太陽が来る**
- 太陽が来たとき、日陰（水色マス）以外にいるヴァンパイアは死亡し、持っている血を全て失う
- タイミングは固定で予測可能 → 運ではなく計算・計画のゲーム
- 日陰の数はプレイヤー数との兼ね合いで調整が必要（多すぎると緊張感がない、少なすぎると椅子取りになる）

### 4. ハンター（移動障害物）
- 黄色い三角マーカーで表される。盤面上の特定のリングを周回している
- ハンターに触れた（同じマスに入った）ヴァンパイアは即死
- 移動パターンは固定・予測可能 → プレイヤーはハンターの位置を計算してルートを選ぶ

### 5. コウモリ（発展カード）
- 洞窟（緑マス）に止まると獲得できる
- カタンの発展カードに相当する一度きりの特殊効果カード
- 手札として伏せて持ち、任意のタイミングで使用可能
- 効果の例（要バランス調整）:
  - 移動力+2（1ターンだけ追加移動）
  - ハンター操作（ハンター1体を1マス移動させる）
  - 血の強奪（他プレイヤーから血を1つ奪う）
  - 日陰生成（1ターンだけ今いるマスを日陰にする）
  - コウモリ飛行（任意の日陰マスにワープ）
- **洞窟に寄る＝遠回り** → 血を取りに行くか、コウモリを取りに行くかのジレンマ

## 勝利条件

- ゲーム終了時（規定ラウンド数 or 村の血が枯渇）に、城に持ち帰ったポイントが最も多いプレイヤーの勝利

## デザイン上の重要原則

1. **「欲張るほど帰りが遠い」**: 盤面の同心円構造がそのまま中心（村）に近づくほどリスクが高まるチキンレースを体現する
2. **予測可能な脅威**: 太陽もハンターもタイミング・位置が読める → 運ではなく判断で死ぬゲーム
3. **引き際の判断**: 血をもう1つ取るか、今すぐ帰るか。コウモリを取りに寄り道するか
4. **プレイヤー間の干渉**: コウモリカードによる妨害、日陰の奪い合い、血の有限性
5. **隠し情報**: コウモリカードは伏せて持つ → 相手の手札が読めない緊張感

# ヴァンパイア・ハウス

中心の村で血を吸い、四隅の城へ持ち帰る。朝までに帰れなければ、すべて失う。

同心円の盤面を舞台にした2〜4人用ボードゲームのデジタル版。
インカの宝石（引き際の判断）とカタン（毎ラウンドのダイスと、それを均していく発展）を
下敷きにしている。

![盤面](docs/board.png)

盤面は写真ではなく、ルール（同心円4リング＋放射線8本）をそのまま描いた図形。
座標はルールから機械的に決まるので、写真とのすり合わせは要らない
（経緯は [`docs/design.md`](docs/design.md) 冒頭）。

## 動かす

```sh
npm install
npm run dev      # http://localhost:5173
```

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run build` | 型チェック＋本番ビルド（`dist/`） |
| `npm test` | ルールとボットのテスト（76件） |
| `npm run balance` | ボット自動対戦によるバランス計測 |

依存はビルドツールのみ。実行時のライブラリは使っていない。

## 遊びかた

- **移動** 毎ターン3歩。同心円に沿って横へ、放射線に沿って内外へ動く
- **血** 中心の村でターンを終えるたびに1つ吸える。自分の城に入れば得点。**持ち帰るまでは0点**
- **月潮** 毎ラウンドの終わりに 2d4。出目が指したリングに立っている者は全員、血を1つ吸える。
  中心に近いリングほど濃い（リング2が37.5%で最も濃く、そこはハンターの巡回路）。
  **足を止める場所を決めた後で振られる**ので、どのリングで待つかがそのまま賭けになる
- **眷属** 自分の城でコウモリを1枚切ると、永続の強化を1体雇える（**1夜1体まで**）。
  当たり幅を広げる《群れ》、取り分を厚くする《牙》、重さに耐える《器》、足を伸ばす《翼》。
  夜を重ねるほど、出目の当たり外れを技術で均せるようになる
- **重さ** 血2つごとに移動力が1減る。欲張るほど帰り道は遠くなる
- **太陽** 4ラウンドごとに夜が明ける。日陰か城にいない者は焼かれ、抱えた血をすべて失う
- **ハンター** 黄色い三角。リング2を1ラウンドに1マスずつ周回する。触れれば即死。
  次の一歩は盤面に予告されるので、死ぬのは常に計算違いのとき
- **洞窟** 通るとコウモリ（発展カード）を1枚引ける。ただし寄り道になる
- **日陰** 定員1人。深部の日陰はハンターの巡回路と重なっている
- **決着** 4夜が明けたら終わり。最終夜の持ち帰りは2点

ダイス（月潮）が決めるのは**稼ぎだけ**で、死因には一切触れない。
太陽もハンターも今までどおり完全に読める ―― 死ぬのは計算違いのときだけ。

2〜4人のホットシート対戦に対応。空いた席はボットが埋める（全席ボットの観戦も可能）。

PWA対応。スマホのブラウザで開いて「ホーム画面に追加」すればアプリのように起動でき、
一度開いたページはオフラインでも遊べる（`public/manifest.webmanifest` と `public/sw.js`）。

ルールの詳細と、企画段階で未決定だった項目をどう確定させたかは
[`docs/design.md`](docs/design.md) にまとめてある。

## 構成

```
src/game/    ルール本体。DOM に依存しない純粋なロジック
src/assets/  企画段階のデザイン画像（board.png。現状どこからも参照していない）
src/ui/      同心円と扇形を描き、当たり判定とハイライトを重ねる SVG 層
docs/        企画書と確定版ルール
scripts/     バランス検証用シミュレーション
```

ゲームロジックと描画が分離してあるので、ルールを変えるときは
`src/game/` のテストだけで挙動を確認できる。
